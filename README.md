# CRYST

A crystal-growing app built with React Router, React, and Supabase.

## Run locally

Use Node.js 22.22.1 or newer.

```sh
npm install
npm run dev
```

The terminal prints the local app URL. Supabase connection details belong in `.env`; `.env.example` lists the required variables. See [Supabase setup](supabase/README.md) for authentication settings, database setup, and progress-saving behavior. Do not rerun a database migration that has already succeeded.

## Checks

```sh
npm run build
npm run typecheck
node --test tests/projectProgress.test.mjs
```

`build/` and `.react-router/` are generated by the development and build commands. `node_modules/` contains installed dependencies. These folders are ignored by Git.

## Project files

- `app/`: routes, components, styles, recipe content, and Supabase integration.
- `public/`: images, fonts, and icons used by the app.
- `supabase/`: database migration and setup instructions.
- `tests/`: project-progress and guest-transfer tests.

The profile page is intentionally a placeholder for a teammate's implementation. Completed-project data is available through `getCompletedProjects()` in `app/lib/projectProgress.js`.
